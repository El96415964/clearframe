Frequently asked questions

What is image metadata?

Image metadata is information stored alongside a picture, such as camera settings, the date a photo was taken, or sometimes location details. Not every image contains this information.

How does ClearFrame help remove metadata?

ClearFrame redraws your image in your browser and exports a new PNG file instead of copying the original file. This usually avoids carrying over the original EXIF metadata. This prototype has not been independently tested against every metadata standard, so it cannot guarantee that every possible extra field is removed.

Is my image uploaded?

The page code processes the selected image locally in your browser and contains no image-upload endpoint or third-party analytics script. The selected file is not sent to a ClearFrame server by this tool.

Will the cleaned image look different?

It should look very similar, but re-encoding can affect color handling, file size, and some image features. Transparent areas are supported when your browser can decode the image.

Can I clean animated images or every image format?

No. The output is a still PNG, so animation is not preserved. Support for formats such as HEIC/HEIF depends on your browser. Files must be 25 MB or smaller.

Should I use this for highly sensitive images?

Do not rely on this prototype as a security guarantee. For sensitive images, verify the output with a trusted metadata inspection tool before sharing it.

Privacy: This static prototype has no analytics, advertising scripts, accounts, or upload endpoint. The selected image is processed locally by your browser.

Known limits: Re-encoding may change color handling or file size. PNG output can be larger than JPEG/WebP. For sensitive images, verify the output with a trusted metadata inspection tool before sharing.

ClearFrame is an independent prototype. No claim of complete metadata removal is made.
