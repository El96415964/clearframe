# ClearFrame

A static browser-based image re-encoding prototype. Images are processed locally in the browser and exported as PNG; the site does not upload images or include analytics or advertising scripts.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then save. Once GitHub Pages finishes deploying, the site should be available at `https://el96415964.github.io/clearframe/`.

## Limitations

This prototype has not undergone independent metadata-forensics testing. Do not rely on it as a guarantee for highly sensitive images. Re-encoding may change color handling or file size; animated images are not preserved as animations.
