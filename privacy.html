Privacy and limitations

ClearFrame is a small browser-based tool that redraws a selected image and exports a new PNG file. It is designed to help people create a fresh copy of an image without carrying over the original file's EXIF metadata.

How your image is processed

The page uses browser image and canvas features to process the selected file on your device. The current version does not contain an image-upload endpoint, account system, analytics script, or advertising script. Your image is not intentionally sent to a ClearFrame server.

What this tool does not promise

ClearFrame is not a certified forensic sanitization tool. The output is expected not to preserve the source file's EXIF metadata, but browser behavior, file formats, color profiles, and metadata types can vary. If the image is sensitive, independently inspect the output with a trusted metadata tool before sharing it.

Image quality and formats

ClearFrame exports a PNG. It may increase file size or alter color handling, and it does not preserve animation; animated images are reduced to a still frame. Some formats, including HEIC/HEIF, may not be supported by your browser.

Information handled by the website

The tool itself does not ask for your name, email address, or an account. The static page does not include its own analytics or advertising code. GitHub Pages, which hosts the site, may process ordinary server request data under GitHub's own policies.

Changes

This is an independent prototype and may change as it is tested. Do not rely on it as the only privacy protection for high-risk or highly sensitive images.
